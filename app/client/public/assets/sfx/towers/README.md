# Tower Sound Effects Directory

Place optional custom `.mp3` or `.wav` sound files here for custom audio.
If a file is present, the sound engine will automatically play it; if absent, the engine falls back to high-fidelity procedural Web Audio synthesis.

## File Naming Conventions

### 1. Shooting Sounds
- `archer_shoot.mp3` (or `.wav`)
- `cannon_shoot.mp3`
- `bomb_shoot.mp3`
- `bell_shoot.mp3`
- `spear_shoot.mp3`
- `gun_shoot.mp3`
- `water_cannon_shoot.mp3`
- `chinthe_shoot.mp3`
- `dragon_shoot.mp3`
- `sein_pyaung_shoot.mp3`

### 2. Impact Sounds
- `archer_impact.mp3` (or `.wav`)
- `cannon_impact.mp3`
- `bomb_impact.mp3`
- `bell_impact.mp3`
- `spear_impact.mp3`
- `gun_impact.mp3`
- `water_cannon_impact.mp3`
- `chinthe_impact.mp3`
- `dragon_impact.mp3`
- `sein_pyaung_impact.mp3`
